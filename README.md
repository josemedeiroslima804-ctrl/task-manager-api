# Task Manager API

API REST desenvolvida para fins de estudo, com o objetivo de aprender os principais conceitos do desenvolvimento Back-end utilizando Python.

## Objetivos

Este projeto faz parte do meu portfólio de desenvolvimento Back-end e tem como foco o aprendizado de:

- Desenvolvimento de APIs REST
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Git e GitHub
- Boas práticas de desenvolvimento

## Funcionalidades

As funcionalidades serão implementadas gradualmente durante o desenvolvimento.

Planejamento inicial:

- [ ] Criar tarefas
- [ ] Listar tarefas
- [ ] Buscar tarefa por ID
- [ ] Atualizar tarefas
- [ ] Excluir tarefas
- [ ] Filtrar tarefas
- [ ] Documentação automática com Swagger
- [ ] Deploy da aplicação

## Tecnologias

- Python 3.11
- FastAPI
- PostgreSQL
- SQLAlchemy
- Git
- GitHub
